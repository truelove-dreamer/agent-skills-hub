这个项目是什么

收录 GitHub 热门的 SKILL.md 智能体技能包，提供周榜（近 7 天涨星）、月榜（近 30 天涨星）、年榜（总星标），并按人群分类。

数据来源与更新

星标数据来自 GitHub REST API，每周由 GitHub Actions 自动更新；完整口径见仓库内的 docs/methodology.md。

收录边界

只收录公开 GitHub 源码且能定位到 SKILL.md、插件入口或套件入口的项目；排除仅 MCP、纯宣传页、无法审阅源码的产品。

核验与安全声明

每个条目带有核验日期，仅表示链接与描述经过人工检查，不构成对技能内容、安全性或质量的背书。安装第三方技能前请阅读其 README、许可证与权限说明。
